isMintable

fun isMintable(): Boolean

True unless a resync has suspended minting on this document (see mintingSuspended) -- i.e. no resync is currently between its discard and its re-anchor. DocumentHistory.canUndo/DocumentHistory.canRedo gate on this in addition to their own stack checks, and updateAsync/undo-redo refuse with YorkieException.Code.ErrRefused via ensureMintableAtEntry while it is false.
